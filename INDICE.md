# Índice de documentación - pymini

Proyecto para la asignatura "compiladores" de la Universidad de Sonsonate.

## Documentos principales (orden recomendado)

1. **README.md** — guía principal paso a paso (empieza aquí)
   - instalación de dependencias
   - compilación del proyecto
   - ejecución de pruebas
   - resolución de problemas comunes

2. **README_FINAL.md** — resumen técnico de la fase 1
   - estadísticas del proyecto
   - características implementadas
   - estructura del código

3. **docs/INICIO_RAPIDO.md** — comandos directos para levantar el proyecto en 5 minutos

## Documentación técnica adicional (docs/)

- **docs/ARCHITECTURE.md** — diseño interno del compilador (para entender el código fuente)
- **docs/EXAMPLES.md** — ejemplos avanzados de código pymini
- **docs/ROADMAP.md** — plan de desarrollo futuro (fases 2-5)
- **docs/CHANGELOG.md** — historial de cambios

## Recomendación

Si es tu primera vez:
1. lee README.md de principio a fin
2. ejecuta los comandos de instalación
3. compila con `make`
4. ejecuta `./run_tests.sh`

Si quieres entender el código:
1. lee docs/ARCHITECTURE.md
2. revisa el código fuente en `src/`

Si quieres ver ejemplos:
1. revisa `tests/` para casos básicos
2. lee docs/EXAMPLES.md para casos avanzados
