# PyMini - Fases 3 y 4 Completadas

## Resumen de Implementación

Este documento describe la implementación de las **Fases 3 y 4** del compilador PyMini, completando un compilador funcional de Python (subset) a código nativo.

---

## Fase 3: Generación de Código y Runtime

### Componentes Implementados

#### 1. Runtime (`src/runtime.c`, `src/runtime.h`)

Sistema de runtime mínimo con las siguientes funcionalidades:

- **`rt_print_int(int x)`**: Imprime enteros con salto de línea
- **`rt_print_bool(int b)`**: Imprime `True` o `False` según el valor booleano
- **`rt_div(int a, int b)`**: División con verificación de división por cero
- **`rt_mod(int a, int b)`**: Módulo con verificación de división por cero
- **`main()`**: Función main real que invoca `__pymini_main()`

#### 2. Generador de Código C (`src/codegen_c.c`, `src/codegen_c.h`)

Traductor de AST anotado a código C válido:

**Características:**
- Genera función `__pymini_main()` para código top-level
- Mapeo de tipos: `int` y `bool` → `int` en C
- Funciones con tipos de retorno inferidos
- Short-circuit evaluation para `and` y `or` usando `&&` y `||`
- Declaración automática de variables locales
- Prototipos de funciones generados automáticamente
- Preservación de precedencia con paréntesis

**Estructuras soportadas:**
- Asignaciones: `x = expr`
- Impresión: `print(expr)` → `rt_print_int/bool(expr)`
- Control de flujo: `if/elif/else`, `while`
- Funciones: `def f(a,b): { ... }` → `int f(int a, int b) { ... }`
- Operadores: aritméticos, relacionales, lógicos
- Llamadas a funciones: `f(a,b)`
- Retornos: `return expr`

**Ejemplo de código generado:**

Entrada (PyMini):
```python
def add(a, b):
{
    return a + b
}

print(add(2, 3))
```

Salida (C):
```c
/* Generated by PyMini Compiler */
#include <stdio.h>
#include "runtime.h"

int add(int, int);

int add(int a, int b) {
    return (a + b);
}

int __pymini_main(void) {
    rt_print_int(add(2, 3));
    return 0;
}
```

## Fase 4: Pipeline, CLI y Optimizaciones

### Componentes Implementados

#### 1. Pipeline de Compilación (`src/pipeline.c`, `src/pipeline.h`)

Pipeline automatizado con los siguientes pasos:

1. **Parsing**: Análisis léxico y sintáctico → AST
2. **Semántica**: Verificación de tipos y scopes → AST anotado + tabla de símbolos
3. **Optimización**: Transformaciones del AST según nivel `-O`
4. **Codegen**: Generación de código C
5. **Compilación GCC**: Invocación de gcc con `runtime.c`
6. **Ejecución** (opcional): Ejecutar el binario generado

**Modos de operación:**
- `PIPELINE_EMIT_C`: Solo genera código C
- `PIPELINE_COMPILE`: Genera ejecutable
- `PIPELINE_RUN`: Compila y ejecuta

**Gestión de archivos:**
- Archivos temporales en `/tmp/` con PID único
- Limpieza automática de temporales (opcional con `--keep-temp`)
- Detección automática de `runtime.c` y `runtime.h`

#### 2. Interfaz CLI (`src/cli.c`, `src/cli.h`)

CLI completo con las siguientes opciones:

```bash
./pymini [opciones] <archivo.pymini>

Opciones:
  --help              Muestra ayuda
  --version           Muestra versión
  --emit-c            Solo genera código C
  --compile           Compila a binario ejecutable
  --run               Compila y ejecuta (por defecto)
  -o <archivo>        Archivo de salida
  -O0                 Sin optimizaciones (por defecto)
  -O1                 Optimizaciones básicas
  -v, --verbose       Modo verbose
  --keep-temp         Mantiene archivos temporales
```

**Ejemplos de uso:**
```bash
# Compilar y ejecutar (por defecto)
./pymini programa.pymini

# Solo generar código C
./pymini --emit-c -o programa.c programa.pymini

# Compilar a ejecutable
./pymini --compile -o programa programa.pymini

# Optimizar y ejecutar
./pymini -O1 --run programa.pymini

# Modo verbose para debugging
./pymini -v --run programa.pymini
```

#### 3. Optimizaciones (`src/opt.c`, `src/opt.h`)

Optimizaciones básicas implementadas en nivel `-O1`:

**a) Constant Folding (Plegado de Constantes)**

Evalúa expresiones constantes en tiempo de compilación:

- Aritméticas: `1 + 2 * 3` → `7`
- Booleanas: `True and False` → `False`
- Unarias: `not True` → `False`, `-5` → `-5`
- Relacionales: `2 < 3` → `True`

**Ejemplo:**
```python
x = 1 + 2 * 3    # Sin optimización: x = (1 + (2 * 3))
                 # Con -O1: x = 7
```

**b) Dead Code Elimination (Eliminación de Código Muerto)**

Elimina código inalcanzable:

- Statements después de `return`
- Ramas inalcanzables en `if` con condición constante

**Ejemplo:**
```python
def f(x):
{
    return x
    print(99)  # ← Eliminado (inalcanzable)
}
```

**c) Copy Propagation (Propagación de Copias)**

Implementación básica para asignaciones simples (limitada en esta versión).

**Entrada** (`test.pymini`):
```python
x = 1 + 2 * 3
print(x)
```

**Sin optimización** (`-O0`):
```bash
./pymini --emit-c -o test.c test.pymini
```

```c
int __pymini_main(void) {
```

**Con optimización** (`-O1`):
```bash
./pymini -O1 --emit-c -o test_opt.c test.pymini
```

```c
int __pymini_main(void) {
    int x;
    x = 7;
    rt_print_int(x);
    return 0;
```

### Ejemplo 2: Programa con Funciones

**Entrada** (`factorial.pymini`):
```python
def factorial(n):
{
    if n <= 1:
    {
        return 1
    }
    else:
    {
        return n * factorial(n - 1)
    }
}

print(factorial(5))
```

**Compilar y ejecutar**:
```bash
./pymini --run factorial.pymini
```

**Salida**:
```

```

**Código C generado** (fragmento):
```c
int factorial(int);

int factorial(int n) {
    if ((n <= 1)) {
        return 1;
    }
    else {
        return (n * factorial((n - 1)));
    }
}

int __pymini_main(void) {
    rt_print_int(factorial(5));
    return 0;
}
```

## Características Técnicas

### Mapeo de Tipos

| PyMini | C | Notas |
|--------|---|-------|
| `int` | `int` | 32-bit signed |
| `bool` | `int` | 0 = False, 1 = True |
| `TY_UNKNOWN` | `int` | Default para retornos |

### Operadores

**Short-circuit evaluation:**
- `a and b` → `(a && b)` en C
- `a or b` → `(a || b)` en C

**División segura:**
- `a / b` → `rt_div(a, b)` cuando `--use-runtime-checks` está activo
- `a % b` → `rt_mod(a, b)` cuando `--use-runtime-checks` está activo

### Gestión de Variables

**Locales:**
- Declaradas al inicio de cada función
- Tipo inferido del primer uso
- Scope limitado a la función

**Globales:**
- Declaradas en `__pymini_main()`
- Scope de todo el módulo

## Arquitectura del Compilador

```
┌─────────────┐
│  main.c     │ ← CLI
│  cli.c      │
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ pipeline.c  │ ← Orquestador
└──────┬──────┘
       │
       ├──► parse_file() ──────────► AST
       │
       ├──► sema_check_ex() ───────► AST anotado + Scope
       │
       ├──► optimize_ast() ────────► AST optimizado
       │
       ├──► codegen_emit_c() ──────► archivo.c
       │
       ├──► run_gcc() ─────────────► binario
       │
       └──► run_binary() ──────────► salida programa
```
